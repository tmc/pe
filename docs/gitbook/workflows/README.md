# Core Workflows

PE supports several primary workflows for prompt engineering, from rapid prototyping to production optimization.

*   [**Running Prompts**](running-prompts.md): Execute prompts interactively or via CLI.
*   [**Evaluation**](evaluation.md): Test prompts rigorously with assertions and metrics.
*   [**Optimization**](optimization.md): Improve prompt performance using advanced algorithms.
*   [**Pipelines**](pipelines.md): Chain commands together for complex data processing.
