# Installation

Use the current installation guide: [INSTALLATION.md](../../INSTALLATION.md).

For source installs:

```bash
go install github.com/tmc/pe/cmd/pe@latest
pe --version
```

Tagged releases publish archives for macOS, Linux, and Windows. See
[INSTALLATION.md](../../INSTALLATION.md) and
[RELEASE_BUILD_MATRIX.md](../../RELEASE_BUILD_MATRIX.md) for current asset names
and build targets.
