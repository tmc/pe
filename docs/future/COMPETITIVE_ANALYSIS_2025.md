## 🔄 Migration Guides

### From promptfoo to PE

```bash
# Convert promptfoo config to PE
pe convert promptfoo-config.yaml pe-config.yaml

# Enhance with PE's advanced features
pe eval pe-config.yaml --metrics bleu,rouge,bertscore,g-eval
pe optimize --method pe2 --iterations 5
pe security test --owasp-complete
```

### From LangSmith to PE

```bash
# Import LangSmith traces
pe import langsmith-traces.json --format pe-evaluation

# Add optimization capabilities
pe optimize imported-prompts/ --method apex --beam-width 5
pe fusion optimized/ --models gpt-4,claude-3 --consensus weighted
```

### From DSPy to PE

```python
# DSPy code

chain_of_thought = dspy.ChainOfThought(...)

# PE equivalent with 2025 advances
pe compose --style dspy context.txt instruction.txt --optimize

pe gaso --system-definition dspy-program.json --multi-objective
```
